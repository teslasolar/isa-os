ISA-OS Terminal Help

System Commands

  • help - Show available commands
  • about - System information
  • version - Show version
  • stats - System statistics
  • uptime - System uptime
  • clear - Clear screen

Module Commands

  • modules - List loaded modules
  • module info <name> - Module details

Agent Commands

  • agents - List active agents
  • agent info <id> - Agent details
  • agent suspend <id> - Suspend agent
  • agent resume <id> - Resume agent

Watchdog Commands

  • watchdog list - List all watchdogs
  • watchdog create <agent> <timeout> - Create watchdog
  • watchdog enable <id> - Enable watchdog
  • watchdog disable <id> - Disable watchdog

ISA-95 Level Commands

  • l0 read <sensor_id> - Read L0 sensor
  • l1 write <actuator_id> <value> - Write L1 actuator
  • l2 alarm <message> - Raise L2 alarm
  • l3 batch start <recipe_id> - Start L3 batch
  • l4 erp sync - Sync with L4 ERP

Configuration

  • config - Show all configuration
  • config get <key> - Get config value
  • config set <key> <value> - Set config value

Error & Diagnostics

  • errors - Show error statistics
  • errors last - Show last error
  • errors clear - Clear error stats

Keyboard Shortcuts

  • F1 - Toggle help panel
  • Ctrl+L - Clear screen
  • Up/Down - Command history
